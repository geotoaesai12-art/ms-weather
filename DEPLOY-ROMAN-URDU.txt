MS WEATHER — SIRF VERCEL PAR LIVE KARNE KA ASAN GUIDE
=====================================================
Website aur backend dono Vercel par chalte hain. Card ki zaroorat nahi.
Aapko koi file khud edit ya delete nahi karni.

STEP 0 — NAYI API KEY (agar abhi nahi banayi)
  1. https://home.openweathermap.org/api_keys kholein.
  2. PURANI key Delete karein (purani key kai baar share ho chuki hai).
  3. Nayi key banayein aur Notepad mein save karein. Kisi ko na dikhayein.
  (Nayi key active hone mein 10 se 120 minute lag sakte hain.)

STEP 1 — GITHUB PAR UPLOAD (double click)
  1. Is folder mein "UPLOAD-TO-GITHUB.bat" par double click karein.
  2. Agar GitHub login maange to browser mein allow kar dein.
  3. Akhir mein "Ho gaya!" likha aaye to upload poora hai.
  (Yeh file purani files khud hata deti hai, aur .env jaisi secret files
   kabhi upload nahi hone deti.)

STEP 2 — VERCEL PAR PROJECT BANAYEIN
  1. https://vercel.com par "Continue with GitHub" se login karein.
  2. Add New > Project dabayein.
  3. Repository "ms-weather" ke saath Import dabayein.
     (Na dikhe to "Adjust GitHub App Permissions" dabayein, ms-weather
      select karein aur Save karein.)

STEP 3 — SETTINGS (bohat kam)
  1. Framework Preset: "Other" rehne dein.
  2. Root Directory: jaisa hai waisa (./) rehne dein.
  3. Build aur Install settings KO MAT BADLEIN. vercel.json khud sambhal leti hai.
  4. "Environment Variables" kholein aur yeh daalein:
       OPENWEATHER_API_KEY  =  aapki NAYI key          (zaroori)
       VITE_CONTACT_EMAIL   =  aapki email              (optional)
       NOTE: yeh sirf Contact page par "Prefer email?" wala card dikhata hai (public email).
       Contact form ke liye neeche STEP 5 dekhein.
  5. "Deploy" dabayein. 2 se 4 minute lagte hain.

STEP 4 — CHECK KAREIN
  1. Vercel jo link de (jaise https://ms-weather.vercel.app) woh kholein.
  2. Alag tab mein  <aapka link>/api/health  kholein.
     "status":"ok" aaye to backend theek hai.
  3. Website par koi shehar search karein (jaise Islamabad).

STEP 5 — CONTACT FORM CHALANA (message seedha aapke Gmail mein)
  Contact form ab asli hai: visitor Send dabata hai aur message aapke Gmail mein
  aa jata hai. Is ke liye ek free email service "Resend" chahiye.
  A) https://resend.com par Sign up karein. Usi Gmail se karein jahan messages
     chahiye. Gmail mein aayi verification email ka link dabayein.
  B) Resend mein API Keys > Create API Key dabayein. Naam: ms-weather.
     Permission: "Sending access". Key copy karein (re_ se shuru hoti hai,
     sirf ek baar dikhti hai).
  C) Vercel > Settings > Environment Variables mein yeh 2 daalein:
       RESEND_API_KEY     =  woh key (re_...)
       CONTACT_TO_EMAIL   =  wohi Gmail jis se Resend par sign up kiya
     (Free plan mein CONTACT_TO_EMAIL wohi hona chahiye jis se sign up kiya.)
  D) Deployments > teen nuqtay > Redeploy.
  E) Website ka Contact page kholkar khud ko ek message bhejein. Gmail ka Inbox
     dekhein (pehli baar Spam bhi). Gmail mein Reply dabane se jawab visitor ko jayega.
  Hadood (free plan, Resend ki site par badal sakti hain): roz 100 email,
  mahine ke 3,000, aur jab tak aap apna domain verify na karein sirf apni email par.
  Baad mein: Resend > Domains mein apna domain (jaise ms-weather.com) verify karein,
  phir Vercel mein CONTACT_FROM = MS Weather <contact@aapka-domain.com> daalein.

AGAR KOI MASLA AAYE
  - Weather na aaye / "Weather service unavailable":
    API key galat hai ya abhi active nahi hui. Vercel > Settings >
    Environment Variables mein key check karein, phir Deployments >
    teen nuqtay > Redeploy karein. (Env variable badalne ke baad
    hamesha Redeploy karna padta hai.)
  - Link kholne par Vercel login maange:
    Vercel > Settings > Deployment Protection mein dekhein.
  - Build fail ho: Vercel ke "Build Logs" ka screenshot bhej dein.
  - Page blank ho: browser mein F12 > Console ka screenshot bhej dein.
  - Contact form "could not send your message" kahe: Vercel > Logs mein
    "mail provider refused" dhoondein. Wahan wajah likhi hoti hai. Sab se aam:
    "You can only send testing emails to your own email address" yaani
    CONTACT_TO_EMAIL wohi nahi jis se Resend par sign up kiya. Key/email badalne
    ke baad Redeploy karna na bhoolein.
  - Contact form kehta hai "several messages already": 10 minute mein 5 se zyada
    message nahi bhej sakte (spam se bachao). Thodi der baad dobara try karein.
  - Pehli search kuch der le sakti hai (function pehli baar jagta hai).

KHAS BAATEIN
  - Vercel ka free (Hobby) plan sirf personal aur non-commercial use ke liye hai.
    Asli kamai wali website ke liye Vercel ki shartein zaroor dekhein.
  - Rate limit aur cache Vercel par utne pakke nahi hote jitne alag server par.
    Is liye weather ke jawab 5 minute ke liye Vercel ke CDN par cache hote hain.
  - Apne computer par chalane ke liye: SETUP-API-KEY.bat (key lagane ke liye),
    phir START-MS-WEATHER.bat.
  - Agar baad mein backend alag jagah rakhein to VITE_API_BASE_URL daalna hoga
    aur vercel.json mein connect-src badalni hogi.
