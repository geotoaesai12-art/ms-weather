MS WEATHER — WEBSITE LIVE KARNE KA ASAN GUIDE
=============================================
Website 2 hisson mein live hoti hai:
  A) BACKEND (API)  -> Render.com par   (yahan aapki API key rehti hai)
  B) FRONTEND (site) -> Vercel.com par  (yeh woh page hai jo log dekhte hain)
Pehle A karein, phir B, phir akhri step.

------------------------------------------------
STEP 0 — API KEY NAYI BANAYEIN (bohat zaroori)
------------------------------------------------
Purani key zip file mein thi, is liye usay use na karein.
1. https://home.openweathermap.org/api_keys kholein.
2. Purani key ko Delete karein.
3. Nayi key banayein aur copy kar lein. Kisi ko na dikhayein.
(Nayi key active hone mein 10 se 120 minute lag sakte hain.)

------------------------------------------------
STEP 1 — CODE GITHUB PAR DALEIN
------------------------------------------------
1. github.com par new repository banayein (Private rakhna behtar hai).
2. Is zip ka poora folder wahan upload karein.
   NOTE: .env file aur node_modules upload NAHI honi chahiye.
   (Is zip mein woh pehle se nikal di gayi hain.)

------------------------------------------------
STEP 2 — BACKEND RENDER PAR (A)
------------------------------------------------
1. render.com par GitHub se login karein.
2. New + > Blueprint select karein, apni repository chunein.
   (render.yaml file khud sab settings bhar degi.)
3. Jab Render puchay to:
     OPENWEATHER_API_KEY = apni nayi key paste karein
     ALLOWED_ORIGINS     = abhi khali chhor dein (Step 4 mein bharenge)
4. Deploy ho jaye to Render ek link dega, jaise:
     https://ms-weather-api.onrender.com
   Isay copy kar lein.
5. Browser mein  <woh link>/api/health  kholein.
   "status":"ok" nazar aaye to backend theek hai.

------------------------------------------------
STEP 3 — FRONTEND VERCEL PAR (B)
------------------------------------------------
1. vercel.com par GitHub se login karein.
2. Add New > Project, wahi repository chunein.
3. Root Directory mein "frontend" select karein.
4. Environment Variables mein yeh dalein:
     VITE_API_BASE_URL  = Step 2 wala Render link (akhir mein / nahi)
     VITE_CONTACT_EMAIL = aapki email (jaise  name@gmail.com)
5. Deploy dabayein. Vercel aapko website ka link dega, jaise:
     https://ms-weather.vercel.app

------------------------------------------------
STEP 4 — AKHRI STEP (dono ko jodna)
------------------------------------------------
1. Render > aapki service > Environment mein jayein.
2. ALLOWED_ORIGINS mein Vercel wala link daalein
   (akhir mein / nahi, bilkul aise):
     https://ms-weather.vercel.app
   Agar apna domain bhi hai to comma laga kar woh bhi daalein.
3. Save karein. Render khud dobara start ho jayega.
4. Ab website kholein aur koi shehar search karein. Chal jani chahiye.

------------------------------------------------
AGAR KOI MASLA AAYE
------------------------------------------------
- Pehli baar site khulne mein 30-60 second lag sakte hain
  (Render ka free plan soya hota hai). Dobara "Try again" dabayein.
- "Weather is unavailable": Render ke Logs dekhein, aur check karein
  ke API key sahi hai aur ALLOWED_ORIGINS bilkul Vercel link jaisa hai.
- Page blank ho: browser mein F12 > Console ka screenshot bhejein.
- Agar Render ke bajaye koi aur host use karein to frontend/vercel.json
  mein connect-src theek rehta hai (https: allowed hai).
